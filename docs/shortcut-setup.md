# iPhone 捷徑安裝（手機 10 秒記一筆）

做一個「記帳」捷徑：點一下（或喊 Siri）→ 選分類 → 打品項 → 打金額 → 完成。
兩人各裝一份，**只有 person 那格不一樣**（綾芸填 `aya`、景皓填 `aras`）。

## 建立步驟（捷徑 App）

打開「捷徑」App → ➕ 新增捷徑，依序加入這些動作：

1. **清單（List）** — 填入分類（跟網站設定裡的一致，可少填只放常用的）：
   `🍜 外食・餐廳`、`🥬 買菜・食材`、`🧻 日用品・雜貨`、`🚗 交通`、`🎬 娛樂・約會`、`📦 其他`
2. **從清單中選取（Choose from List）** — 來源選上一步的清單，提示寫「分類？」
3. **要求輸入（Ask for Input）** — 文字，提示「品項？」
4. **要求輸入（Ask for Input）** — **數字**，提示「多少錢？」
5. **從選單中選取（Choose from Menu）** — 提示「共同開銷？」，選項「是」「否」
   - 「是」分支：加動作 **文字（Text）** 內容填 `true`
   - 「否」分支：加動作 **文字（Text）** 內容填 `false`
6. **字典（Dictionary）** — 建這幾組：
   | 鍵 | 型別 | 值 |
   |---|---|---|
   | token | 文字 | Code.gs 裡設的 TOKEN |
   | action | 文字 | `add` |
   | txn | **字典** | ↓ 子字典 |
   - txn 子字典：
     | 鍵 | 型別 | 值 |
     |---|---|---|
     | person | 文字 | `aya` 或 `aras`（← 兩人唯一的差別） |
     | type | 文字 | `expense` |
     | category | 文字 | 變數：**從清單中選取的結果** |
     | item | 文字 | 變數：**步驟3的輸入** |
     | amount | 數字 | 變數：**步驟4的輸入** |
     | shared | **布林** | 變數：**步驟5的文字**（或直接固定 true） |
     | source | 文字 | `shortcut` |
7. **取得 URL 內容（Get Contents of URL）**
   - URL：Apps Script 的 `/exec` 網址
   - 方法：**POST**，請求本文：**JSON**，內容選上一步的**字典**
8. **顯示通知（Show Notification）** — 內容填「✅ 記好了」

捷徑改名成「記帳」→ 之後可以「嘿 Siri，記帳」。加到主畫面或桌面小工具更快。

## 小抄

- 收入平常用網站記就好（比較少發生）；真想要捷徑版，複製一份把 `type` 改 `income`、`shared` 改 `false`。
- 沒網路時會失敗（通知會報錯），到有網路的地方再記一次即可。
- 日期不用填，後端會自動用「今天」。
